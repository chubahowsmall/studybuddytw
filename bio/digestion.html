人體如何獲得養分

植物自己做養分，人只能靠吃。但飯、肉、油都是大分子，太大了進不了細胞，所以要先消化成小分子，再由小腸吸收進血液。消化系統圖幾乎每份考卷都有題組，每個器官都要能指出來。

一、消化系統的構造與功能★★★ 必考

  • 消化：把大分子養分分解成小分子，才能被吸收。分成物理性消化（咀嚼、胃腸蠕動、膽汁乳化脂質，只把食物顆粒變小、物質本質不變，以增加與酵素接觸的表面積）和化學性消化（靠酵素把大分子分解成小分子）。
  • 消化系統＝消化道＋消化腺。消化道是食物經過的路：口腔 → 咽 → 食道 → 胃 → 小腸 → 大腸 → 肛門。
  • 消化腺：唾腺、胃腺、肝臟、胰臟、腸腺。肝、胰分泌的消化液經導管送到小腸，食物不會經過肝臟和胰臟。
  • 胃：胃液含鹽酸和酵素，強酸性能殺菌並幫助胃液中的酵素作用；初步分解蛋白質；幾乎不吸收養分。
  • 小腸：消化道中最長；內壁有皺褶和絨毛，增加吸收的表面積；有膽汁、胰液、腸液作用，是消化、吸收養分和吸收大部分水分（約 80～90%）最主要的器官。絨毛內的微血管吸收葡萄糖、胺基酸與水分；中央的乳糜管（細小淋巴管）吸收脂肪酸與甘油（脂溶性養分）。
  • 大腸：比小腸粗而短，沒有皺褶、沒有絨毛、沒有消化酵素，主要回收剩餘水分和部分礦物質形成糞便，再由肛門排出（稱為排遺）。盲腸末端有闌尾，「盲腸炎」其實是闌尾發炎。

易錯陷阱
  • 肝臟、胰臟、膽囊不是消化道，「食物經過肝臟或胰臟」是錯的。消化道兼管壁內消化腺的器官只有胃（胃腺）與小腸（腸腺）；食道、大腸無消化腺。
  • 消化液由導管送入消化道，絕非由血液運送：消化腺屬於外分泌腺，血漿中不含任何消化酵素（如胰液、胃蛋白酶都不會在血漿裡）。
  • 吸收養分與大部分水分（約 80～90%）最主要的器官皆是小腸，不是胃也不是大腸；大腸負責回收剩餘水分（拉肚子時主要是大腸吸水減少），且大腸無皺褶、無絨毛、無消化酵素。
  • 排遺 ≠ 排泄：肛門排出未消化吸收的糞便稱為排遺作用；排出細胞代謝廢物（如尿素、CO₂）才叫排泄作用。
  • 飯後小腸流出血液的成分變化（跨 3-2 必考）：流出端微血管的葡萄糖↑、胺基酸↑、CO₂↑、O₂↓；但不會增加大分子「蛋白質」（蛋白質必先分解成胺基酸才被吸收）。
  • 小腸的絨毛和植物的根毛道理一樣：都是透過細小突起大幅增加吸收的表面積。
  • 膽汁乳化脂質、牙齒咀嚼、胃腸蠕動都是物理性消化（只把食物變小以增加與酵素接觸的表面積）；靠酵素分解才是化學性消化。

二、消化液與養分的分解★★★ 必考

  • 唾液（唾腺 → 口腔）：含澱粉酶，把澱粉分解成較小的醣。
  • 胃液（胃腺 → 胃）：含鹽酸（殺菌、提供適合酵素作用的酸性環境）和分解蛋白質的酵素，初步分解蛋白質。
  • 膽汁（肝臟製造、膽囊儲存 → 小腸）：不含酵素，把脂質乳化成小油滴（物理性消化）。
  • 胰液（胰臟 → 小腸）：含多種酵素，能分解醣類、蛋白質、脂質。腸液（腸腺 → 小腸）：含酵素，能分解醣類和蛋白質。
  • 最後產物：澱粉 → 葡萄糖；蛋白質 → 胺基酸；脂質 → 脂肪酸和甘油。維生素、礦物質、水本來就是小分子，不用消化。

觀念釐清：「大顆粒變小」跟「大分子變小」哪裡不一樣？

把每一條長珍珠項鍊想成一個大分子（例如澱粉），項鍊上的每一顆單獨珍珠想成小分子（例如葡萄糖）：

消化類型改變的層次珍珠項鍊比喻本質改變？／靠酵素？
物理性消化 大顆粒 → 小顆粒 把糾結成一大坨的項鍊扯開分成小把；每一條項鍊本身還是連在一起。 不變、不用酵素（咀嚼、蠕動、膽汁乳化油滴）。變小後細胞仍吸收不了，目的是增加與酵素接觸的表面積。
化學性消化 大分子 → 小分子 用剪刀（酵素）把每條項鍊剪開，變成一顆一顆散落的珍珠。 變成新物質、靠酵素（澱粉 → 葡萄糖、蛋白質 → 胺基酸、脂質 → 脂肪酸＋甘油），小到能通過細胞膜被吸收。

生活實例（嚼白飯變甜）：剛咬兩下把飯粒咬碎還不甜，這只是大顆粒變小顆粒（物理性）；多嚼幾十秒覺得甜甜的，是唾液酵素把澱粉拆成了麥芽糖，這才是大分子變小分子（化學性）。

練習：物理性消化還是化學性消化？

易錯陷阱
  • 膽汁是肝臟製造的，膽囊只負責儲存。膽汁不含酵素，是乳化脂質（把大油滴打散成小油滴），不是「分解」脂質。
  • 含鹽酸的只有胃液；胃液鹽酸負責殺菌與提供強酸環境助胃蛋白酶作用，但鹽酸本身不能直接分解蛋白質；胃液也不分解澱粉和脂質。
  • 吃酵素或口服胰島素為何無效（2-2＋2-4 跨節必考！）：市售食用酵素與糖尿病藥物胰島素的主要成分皆為蛋白質，吃進胃中會被強酸與胃蛋白酶分解而失去原本功能，因此胰島素須採注射方式。
  • 器官切除與代償對照：① 切除胰臟：國中範圍內唯有胰液含分解脂質的酵素，故會喪失脂質的化學性消化；② 唾液缺乏澱粉酶：口腔雖無法初步分解澱粉，但到達小腸仍可由胰液、腸液分解吸收；③ 切除膽囊：肝臟仍可製造膽汁，但無法集中大量釋出，吃油膩食物較難乳化（宜少油）。
  • pH 曲線尾端判讀陷阱：若弱鹼酵素（胰液）曲線在 pH 7 處尚未歸零，題目說「在中性環境完全無作用」就是錯的！另外三種人體消化酵素的最適溫度皆約 37°C。
  • 在小腸作用的消化液有膽汁、胰液、腸液三種。
  • 人體沒有分解纖維素的酵素，胰液也不能分解纖維素，所以纖維素不能被吸收、不能提供能量。但它會隨食物進入大腸吸水膨脹、刺激腸道蠕動，幫助排便、預防便秘。
  • 生活素養（幽門螺旋桿菌）：能在強酸胃中生存並破壞胃黏膜屏障、造成胃潰瘍；因為它屬於細菌，臨床上可用抗生素治療（呼應 3-3）。
