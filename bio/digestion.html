人體如何獲得養分

植物自己做養分，人只能靠吃。但飯、肉、油都是大分子，太大了進不了細胞，所以要先消化成小分子，再由小腸吸收進血液。消化系統圖幾乎每份考卷都有題組，每個器官都要能指出來。

一、消化系統的構造 二、消化液與養分的分解 小測驗

一、消化系統的構造與功能★★★ 必考

  • 消化：把大分子養分分解成小分子，才能被吸收。分成物理性消化（咀嚼、胃腸蠕動、膽汁乳化脂質，只把食物顆粒變小、物質本質不變，以增加與酵素接觸的表面積）和化學性消化（靠酵素把大分子分解成小分子）。
  • 消化系統＝消化道＋消化腺。消化道是食物經過的路：口腔 → 咽 → 食道 → 胃 → 小腸 → 大腸 → 肛門。
  • 消化腺：唾腺、胃腺、肝臟、胰臟、腸腺。肝、胰分泌的消化液經導管送到小腸，食物不會經過肝臟和胰臟。
  • 胃：胃液含鹽酸和酵素，強酸性能殺菌並幫助胃液中的酵素作用；初步分解蛋白質；幾乎不吸收養分。
  • 小腸：消化道中最長；內壁有皺褶和絨毛，增加吸收的表面積；有膽汁、胰液、腸液作用，是消化、吸收養分和吸收大部分水分最主要的器官。葡萄糖、胺基酸進入絨毛裡的微血管。
  • 大腸：比小腸粗而短，吸收水分和部分礦物質；殘渣在這裡形成糞便。盲腸末端有闌尾，「盲腸炎」其實是闌尾發炎。

易錯陷阱
  • 肝臟、胰臟不是消化道，「食物經過肝臟」是錯的。
  • 吸收養分最主要的器官是小腸，不是胃。小腸和大腸都能吸收水分，而且大部分的水分其實是由小腸吸收，剩餘的才由大腸吸收。
  • 小腸的絨毛和植物的根毛道理一樣：都是增加吸收的表面積。
  • 膽汁乳化脂質、牙齒咀嚼、胃腸蠕動都是物理性消化（只把食物變小以增加與酵素接觸的表面積）；靠酵素分解才是化學性消化。

二、消化液與養分的分解★★★ 必考

  • 唾液（唾腺 → 口腔）：含澱粉酶，把澱粉分解成較小的醣。
  • 胃液（胃腺 → 胃）：含鹽酸（殺菌、提供適合酵素作用的酸性環境）和分解蛋白質的酵素，初步分解蛋白質。
  • 膽汁（肝臟製造、膽囊儲存 → 小腸）：不含酵素，把脂質乳化成小油滴（物理性消化）。
  • 胰液（胰臟 → 小腸）：含多種酵素，能分解醣類、蛋白質、脂質。腸液（腸腺 → 小腸）：含酵素，能分解醣類和蛋白質。
  • 最後產物：澱粉 → 葡萄糖；蛋白質 → 胺基酸；脂質 → 脂肪酸和甘油。維生素、礦物質、水本來就是小分子，不用消化。

澱粉從口腔開始，蛋白質從胃開始，脂質到小腸才開始

觀念釐清：「大顆粒變小」跟「大分子變小」哪裡不一樣？

把每一條長珍珠項鍊想成一個大分子（例如澱粉），項鍊上的每一顆單獨珍珠想成小分子（例如葡萄糖）：

消化類型改變的層次珍珠項鍊比喻本質改變？／靠酵素？
物理性消化 大顆粒 → 小顆粒 把糾結成一大坨的項鍊扯開分成小把；每一條項鍊本身還是連在一起。 不變、不用酵素（咀嚼、蠕動、膽汁乳化油滴）。變小後細胞仍吸收不了，目的是增加與酵素接觸的表面積。
化學性消化 大分子 → 小分子 用剪刀（酵素）把每條項鍊剪開，變成一顆一顆散落的珍珠。 變成新物質、靠酵素（澱粉 → 葡萄糖、蛋白質 → 胺基酸、脂質 → 脂肪酸＋甘油），小到能通過細胞膜被吸收。

生活實例（嚼白飯變甜）：剛咬兩下把飯粒咬碎還不甜，這只是大顆粒變小顆粒（物理性）；多嚼幾十秒覺得甜甜的，是唾液酵素把澱粉拆成了麥芽糖，這才是大分子變小分子（化學性）。

練習：物理性消化還是化學性消化？

易錯陷阱
  • 膽汁是肝臟製造的，膽囊只負責儲存。膽汁不含酵素，是乳化脂質（把大油滴打散成小油滴），不是「分解」脂質。
  • 含鹽酸的只有胃液；胃液不分解澱粉和脂質。
  • 在小腸作用的消化液有膽汁、胰液、腸液三種。
  • 人體沒有分解纖維素的酵素，胰液也不能分解纖維素，所以纖維素不能被吸收、不能提供能量。但它還是有用：會隨食物進入大腸，吸水讓糞便變軟、體積變大，刺激腸道蠕動，幫助排便、預防便秘；吃了也比較有飽足感。
