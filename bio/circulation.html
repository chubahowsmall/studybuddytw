人體的循環

小腸吸收的養分、肺吸進的氧氣，要靠血液送到全身每個細胞；細胞產生的二氧化碳和廢物，也靠血液帶走。推動血液的是心臟，運送的管道是血管。另外，從血管滲出去的液體，會由淋巴系統收回來。心臟圖和魚尾鰭幾乎每份考卷都有。

一、血液的組成★★★ 必考

  • 人體的循環＝心血管系統（心臟、血管、血液）＋淋巴系統（淋巴、淋巴管、淋巴結）。
  • 血液＝血漿（淡黃色液體，約占一半以上）＋血球（紅血球、白血球、血小板）。
  • 血漿：大部分是水，運送養分、廢物、二氧化碳、激素等物質；抗體也在血漿中。
  • 紅血球：數量最多；成熟的紅血球沒有細胞核（人類等哺乳類）；含血紅素（含鐵），運送氧氣。
  • 白血球：體積最大、數量最少、有細胞核；能穿出微血管、吞噬病原體，負責防禦。
  • 血小板：體積最小、沒有細胞核（細胞的碎片），幫助血液凝固、止血。
  • 含氧多的充氧血是鮮紅色，含氧少的缺氧血是暗紅色。

易錯陷阱
  • 「白血球數量最多」是錯的，最多的是紅血球。體積：白血球＞紅血球＞血小板。
  • 運送氧氣靠紅血球的血紅素；運送養分、廢物、二氧化碳主要靠血漿。
  • 要檢驗 DNA 得用有細胞核的白血球。魚、青蛙、雞的紅血球有細胞核，人的成熟紅血球沒有。

二、血管、脈搏與魚尾鰭觀察（實驗 3-2、3-3）★★★ 必考

  • 動脈：把血液帶離開心臟；管壁厚、有彈性；血壓最大、流速快。心臟每收縮一次，動脈管壁就擴張一次，這就是脈搏。
  • 靜脈：把血液送回心臟；管壁薄、彈性小、血壓低；四肢的靜脈有瓣膜，防止血液逆流。抽血、打點滴通常在靜脈。
  • 微血管：最細，管壁只有一層細胞；血流最慢，是血液和細胞交換物質的地方。
  • 流過小腸絨毛後，和小動脈相比，小靜脈的血液養分、二氧化碳、廢物較多，氧氣較少。
  • 血液流向：心臟 → 動脈 → 微血管 → 靜脈 → 心臟。
  • 實驗 3-2：正常時脈搏＝心跳次數。量脈搏用食指和中指（也可加無名指），輕按大拇指那一側的手腕內側，不用拇指。聽診器聽到「噗—通」兩聲是一次心跳（瓣膜關閉的聲音）。運動後心跳、脈搏都變快。
  • 實驗 3-3：用沾濕的棉花蓋住小魚的頭部和鰓蓋，保持鰓濕潤、讓小魚能呼吸；先用低倍鏡觀察。一顆一顆流動的是紅血球；最細的血管（微血管）血流最慢。

易錯陷阱
  • 血管是依「離開或回到心臟」分類，不是依含氧多少。肺動脈是缺氧血、肺靜脈是充氧血。
  • 抽血綁住上臂，浮起來的是靜脈：血液流回心臟的路被擋住，靜脈血變多。
  • 「噗—通」是 1 次心跳。1 分鐘心跳 72 次，會聽到 144 個聲音。
  • 分辨魚尾鰭的血管不能看顏色，要看分支或匯集。影像顛倒不影響判斷血管種類；判斷方位時才要反過來。

三、心臟與體循環、肺循環★★★ 必考

  • 心臟在胸腔中央偏左，有 4 個腔室：右心房、右心室、左心房、左心室。心房接靜脈（血流回心臟），心室接動脈（把血送出去）。
  • 左心室的管壁最厚，因為要把血送到全身。
  • 瓣膜：在心房和心室之間、心室和動脈之間，防止血液逆流。
  • 心臟的收縮與舒張：心房收縮 → 血液流入心室；心室收縮 → 血液流入動脈；心房、心室舒張 → 血液流回心臟。
  • 心音：心室收縮時，心房和心室之間的瓣膜關閉；心室舒張時，心室和動脈之間的瓣膜關閉。血液撞擊瓣膜發出聲音，所以一次心跳有「噗、通」兩個心音。
  • 體循環：左心室 → 主動脈 → 全身微血管 → 大靜脈 → 右心房（充氧血 → 缺氧血）。
  • 肺循環：右心室 → 肺動脈 → 肺部微血管 → 肺靜脈 → 左心房（缺氧血 → 充氧血）。
  • 心臟右半邊是缺氧血，左半邊是充氧血，左右不相通。
  • 記法：左體右肺（左心室出發是體循環，右心室出發是肺循環）；要換邊（從左心出去會回到右心，從右心出去會回到左心）。

易錯陷阱
  • 心房接靜脈、心室接動脈；「主動脈和心房相連」是錯的。
  • 從手臂打點滴：藥物 → 大靜脈 → 右心房 → 右心室 → 肺動脈 → 肺 → 肺靜脈 → 左心房 → 左心室 → 主動脈 → 全身。要先經過肺循環！
  • 小腸吸收的養分也是經由靜脈回到心臟，先進入右心房。
  • 心臟圖是面對面看：圖的左邊是心臟的右邊。

四、淋巴系統★★ 常考

  • 血液流經微血管時，一部分血漿滲出到細胞之間，成為組織液。細胞從組織液得到養分和氧氣，也把廢物排進組織液。
  • 大部分組織液回到微血管；一部分進入淋巴管，就叫做淋巴。所以組織液和淋巴的成分最相似。
  • 淋巴系統：淋巴、淋巴管、淋巴結。淋巴管末端封閉，有瓣膜，淋巴只往一個方向流，靠肌肉收縮推動，最後流入靠近心臟的靜脈，所以淋巴進入心臟時，最先到右心房。
  • 淋巴中有白血球（主要是淋巴球），沒有紅血球。
  • 淋巴結在頸部、腋下、鼠蹊部等地方，能過濾病原體；感染時可能腫大。
  • 功能：① 回收組織液（從微血管滲出的血漿）送回血液 ② 防禦疾病。另外，小腸絨毛裡的淋巴管又叫乳糜管，可以吸收脂溶性養分。

組織液和淋巴：點點看

易錯陷阱
  • 淋巴最後流入靜脈，不是動脈。
  • 淋巴沒有紅血球；「淋巴中的紅血球比血液多」是錯的。
  • 組織液是血漿滲出來形成的；紅血球留在血管裡，白血球可以穿出微血管。
