人體的循環

小腸吸收的養分、肺吸進的氧氣，要靠血液送到全身每個細胞；細胞產生的二氧化碳和廢物，也靠血液帶走。推動血液的是心臟，運送的管道是血管。另外，從血管滲出去的液體，會由淋巴系統收回來。心臟圖、血管血壓流速和魚尾鰭幾乎每份考卷都有。

一、血液的組成★★★ 必考

  • 人體的循環＝心血管系統（心臟、血管、血液）＋淋巴系統（淋巴、淋巴管、淋巴結）。
  • 血液＝血漿（淡黃色液體，約占 55%）＋血球（紅血球、白血球、血小板，約占 45%）。醫院抽血檢驗若要離心分層，需先加入抗凝血劑避免凝固。
  • 血漿：約 90% 是水，負責運送養分、廢物、二氧化碳、激素等物質；抗體也在血漿中。血漿不含消化酵素（消化酵素只在消化道內作用）。
  • 紅血球：數量最多、呈雙凹圓盤狀（增加表面積利於攜氧）；成熟的紅血球沒有細胞核（人類等哺乳類）；含血紅素（含鐵），負責運送氧氣。
  • 白血球：體積最大、數量最少、有細胞核；能做變形蟲運動穿出微血管壁、吞噬病原體，負責防禦。
  • 血小板：體積最小、沒有細胞核（細胞的碎片），受傷時協助血液凝固、止血。
  • 含氧多的充氧血是鮮紅色，含氧少的缺氧血是暗紅色。

易錯陷阱
  • 「白血球數量最多」是錯的，最多的是紅血球。體積：白血球 ＞ 紅血球 ＞ 血小板；數量：紅血球 ＞ 血小板 ＞ 白血球。
  • 運送氧氣靠紅血球的血紅素；運送養分、廢物、二氧化碳主要靠血漿。血漿不含消化酵素（常考混充選項！）。
  • 一氧化碳（CO）中毒：熱水器通風不良會產生一氧化碳，CO 與紅血球內血紅素的結合能力遠強於氧氣，導致紅血球無法攜帶氧氣，使身體嚴重缺氧。
  • 要檢驗 DNA 得用有細胞核的白血球。魚、青蛙、鳥類的紅血球有細胞核，但人類（哺乳類）的成熟紅血球沒有。

二、血管、脈搏與魚尾鰭觀察（實驗 3-2、3-3）★★★ 必考

  • 動脈：把血液帶離開心臟；管壁最厚、彈性大；血壓最大、流速最快。心臟每收縮一次，動脈管壁就隨血壓波動擴張一次，這就是脈搏。
  • 微血管：最細，管壁只有一層細胞，僅容紅血球單列通過；血流速度最慢，是血液和組織細胞交換物質的地方。
  • 靜脈：把血液送回心臟；管壁較薄、彈性小、血壓最低（無脈搏）；四肢的靜脈有瓣膜，防止血液逆流。抽血、打點滴通常在靜脈。
  • 血液流向：心臟 → 動脈 → 微血管 → 靜脈 → 心臟。
  • 實驗 3-2（脈搏與心跳）：正常時脈搏＝心跳次數。量脈搏用食指和中指（可加無名指）輕按大拇指側手腕內側的橈動脈；不用大拇指，因為大拇指本身動脈較粗、有明顯脈搏，容易與受測者混淆。聽診器聽到「噗—通」兩聲是一次心跳（瓣膜關閉的聲音）。運動後心跳、脈搏都變快。
  • 實驗 3-3（觀察小魚尾鰭）：選尾鰭是因為薄且透光、容易觀察；用沾濕的棉花蓋住魚頭和鰓蓋，保持鰓濕潤以維持呼吸；先用複式顯微鏡低倍鏡觀察（視野大、亮度高、易追蹤血流）。一顆一顆流動的是紅血球；最細的微血管血流最慢。

易錯陷阱
  • 血壓 vs 流速：血壓最低的是靜脈（不是微血管）；血流速度最慢的才是微血管（不是靜脈）。
  • 血管是依「離開或回到心臟」分類，不是依含氧多少。肺動脈是缺氧血、肺靜脈是充氧血。
  • 抽血綁住上臂，浮起來的是靜脈：血液流回心臟的路被擋住，靜脈血變多。
  • 「噗—通」是 1 次心跳。1 分鐘心跳 72 次，會聽到 144 個聲音；靜脈沒有脈搏。
  • 分辨魚尾鰭的血管不能看顏色或只看粗細，要看分支（小動脈）、紅血球單列慢行（微血管）、匯集（小靜脈）。影像顛倒不影響判斷血管種類；判斷魚頭方位時才要「上下左右皆反過來」。

三、心臟與體循環、肺循環★★★ 必考

  • 心臟在胸腔中央偏左，有 4 個腔室：右心房、右心室、左心房、左心室。心房接靜脈（血流回心臟），心室接動脈（把血送出去）。
  • 左心室的管壁最厚，因為要把血推向全身。
  • 瓣膜：位於心房和心室之間（房室瓣）、心室和動脈之間（半月瓣），防止血液逆流。心房與靜脈之間沒有瓣膜。
  • 冠狀動脈：由主動脈基部分支而出，包覆在心臟表面，負責供應心肌細胞所需的氧氣和養分（心臟腔室內的血液不直接供應心肌）；若阻塞會引發心肌梗塞。
  • 心臟的收縮與舒張：心房收縮 → 血液流入心室；心室收縮 → 血液流入動脈；心房、心室舒張 → 血液流回心臟。
  • 心音：心室收縮時，房室瓣關閉（「噗」）；心室舒張時，半月瓣關閉（「通」）。血液撞擊關閉的瓣膜發出聲音，所以一次心跳有「噗、通」兩個心音。
  • 體循環：左心室 → 主動脈 → 全身微血管 → 大靜脈 → 右心房（充氧血 → 缺氧血）。
  • 肺循環：右心室 → 肺動脈 → 肺部微血管 → 肺靜脈 → 左心房（缺氧血 → 充氧血）。
  • 心臟右半邊是缺氧血，左半邊是充氧血，左右不相通。記法：左體右肺、出發換邊。
  • 醫療時事連結：葉克膜（ECMO）可在重症時暫時代替心肺循環與氣體交換；AED（自動體外心臟電擊去顫器）可協助心跳異常者恢復正常節律。

房接靜脈、室接動脈；右邊缺氧、左邊充氧；靜脈點滴進右房、動脈導管進左室

易錯陷阱
  • 114 段考熱門對照（順流點滴 vs 逆流心導管）：
    • 從手臂靜脈打點滴：藥物順著靜脈血 → 大靜脈 → 最先進入右心房 → 必須先經過肺循環 → 再從左心室送到全身。
    • 從手腕橈動脈做心導管手術：導管是沿著動脈逆流而上 → 主動脈 → 最先進入左心室（或直接抵達主動脈基部的冠狀動脈），不會先進右心房！
  • 冠狀動脈從主動脈基部分支供應心肌；心臟腔室裡的血液不能直接拿來養心肌。
  • 心房接靜脈、心室接動脈；「主動脈和心房相連」或「心房與靜脈間有瓣膜」都是錯的。
  • 小腸吸收的養分經靜脈回心臟，也是最先進入右心房。
  • 心臟圖是面對面看：圖的左邊是心臟的右邊。

四、淋巴系統★★ 常考

  • 血液流經微血管時，一部分血漿自微血管壁滲出到細胞之間，成為組織液。細胞從組織液獲得養分和氧氣，也把廢物排進組織液。
  • 大部分組織液回到微血管；一部分進入淋巴管，就叫做淋巴。因此組織液和淋巴的成分最相似。
  • 淋巴系統包含淋巴、淋巴管、淋巴結。淋巴管末端封閉（盲端），內部有瓣膜，淋巴只能單向流動，靠周圍肌肉收縮推動（非心臟直接推動），最後匯入靠近心臟的靜脈，進入心臟時最先到達右心房。
  • 淋巴中含有白血球（主要是淋巴球），沒有紅血球、也沒有血小板。
  • 淋巴結分布於頸部、腋下、鼠蹊部等處，內含大量白血球，能過濾病原體；身體發炎或感染時常會腫大。
  • 功能：① 回收組織液送回血液循環（若淋巴管阻塞，組織液堆積會造成水腫） ② 防禦疾病。此外，小腸絨毛內的淋巴管又稱乳糜管，可吸收脂溶性養分。

組織液和淋巴：點點看

四大液體比一比：血液・血漿・組織液・淋巴

液體所在位置水／養分／廢物紅血球・血小板白血球
血液血管、心臟內有有有
血漿血管內（血液去除血球）有無無
組織液組織細胞之間（血漿滲出）有無少量（穿出微血管）
淋巴淋巴管內（組織液流入）有無有（淋巴球等）

必考口訣：成分最相似＝組織液與淋巴；與其他三者差異最大＝血液（只有完整的血液同時含紅血球與血小板）。

易錯陷阱
  • 跌倒擦傷破皮時，傷口表面滲出清澈或淡黃色的透明液體，那是組織液（不是淋巴，也不是膿）。
  • 淋巴最後流入靜脈，不是動脈；進入心臟最先到達右心房。
  • 淋巴沒有紅血球；「淋巴中的紅血球比血液多」是錯的。
  • 組織液是由血漿滲出形成；紅血球無法穿過微血管壁，但白血球可以變形穿出微血管。
