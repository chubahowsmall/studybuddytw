## 5. 協作規範與設計／技術備忘

1. **協作規範（詳見根目錄 `AGENTS.md`）**：
   - 全程使用繁體中文溝通。
   - **修改、新增或刪除任何檔案前，必先列出預計變動內容並取得使用者明確同意。**
   - 較大的視覺改動或新插圖，先用 `generative_ui` 製作互動示意圖供使用者預覽確認後再套用至專案。
   - 完成修改後提供繁體中文 Git Commit Log；變更共用 CSS/JS 記得同步推進 `?v=N`（目前為 `?v=13`）。
2. **擬真科學插畫＋向量標註最佳實務（3-1 已驗證成功模式）**：
   - 使用 `image-generator` 生成**完全無文字、無箭頭**的溫暖水彩＋細筆教科書風 3D 科學剖面插畫（背景 `#f8f5ee`，JPEG 品質 85 最佳化至約 100～150 KB 存入 `bio/img/`）。
   - 透過像素採樣與裁切疊點驗證精準座標後，在網頁以 `<svg>` 載入底圖並疊加清晰向量繁中標註與流向箭頭，提供「隱藏標註（自我測驗）」與「放大檢視細節」切換。
   - **重要避坑**：在對話框 `<agent-embed>` 預覽含本地圖片的 HTML artifact 時，不可只寫相對路徑 `href="xxx.jpg"`（會被隔離 iframe 擋掉），須轉成 inline `data:image/jpeg;base64,...` 嵌進預覽 HTML；正式寫入專案網頁時再改回相對路徑 `img/xxx.jpg`。
3. **小測驗插圖題模式**：
   - `B.quiz()` 原生支援每題物件的 `fig` 欄位（渲染於 `<figure>` 中），可直接放入高解析向量 SVG 製作實驗／圖表判讀題。
4. **Windows 無頭瀏覽器產出 PDF 備忘**：
   - 呼叫 `msedge.exe` / `chrome.exe` 須搭配 `Start-Process -Wait -PassThru`、獨立 `--user-data-dir` 與 `--no-pdf-header-footer`，先輸出純英文檔名再 `Copy-Item` 為中文檔名，且須於沙盒外執行。
